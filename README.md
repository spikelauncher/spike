# Spike Launcher 2.0.5 Beta

Лаунчер Minecraft для Windows, Linux и macOS на Kotlin Compose Desktop и Java.

Главная идея 2.0 — сборки. У каждой своя версия Minecraft, загрузчик, моды, настройки и папка с игрой, так что наборы модов друг другу не мешают.

Загрузки: [GitHub Releases](https://github.com/spikelauncher/spike/releases)

## Что умеет

- Ставит и запускает Minecraft: версии берутся из каталога Mojang.
- Vanilla, Fabric и Forge. NeoForge пока нет.
- Офлайн-профили без регистрации. Для сторонних серверов авторизации есть вход через authlib-injector.
- Моды с Modrinth: поиск под версию и загрузчик сборки, установка вместе с зависимостями, включение, выключение и удаление.
- Ресурспаки для каждой сборки отдельно: импорт и включение/выключение.
- Сам подбирает память и JVM-аргументы под Java, версию игры, моды и железо. Можно выставить вручную.
- Логи каждой сборки и разбор вылетов: лаунчер ищет известные ошибки и моды, классы которых есть в стеке. Если подозреваемый нашёлся, игру можно проверить во временной копии сборки без этого мода.
- Проверка модов на подозрительные признаки (обфускация, запуск процессов и т. п.). Это эвристика, а не антивирус.
- Перевод описаний модов на русский через бесплатные веб-сервисы, без API-ключа. Включается в настройках.
- Ghost Mode: на время игры окно лаунчера закрывается, запуск ведёт лёгкий фоновый процесс. После выхода из игры лаунчер открывается снова.
- Обновления через GitHub Releases: лаунчер скачивает установщик и сверяет SHA-256, а запускаете его вы. Автопроверку можно отключить.
- Светлая и тёмная тема.
- Автоадаптация эффектов интерфейса: начальный режим учитывает CPU, память и программную отрисовку, затем корректируется по задержкам кадров при взаимодействии. На слабом железе снижается нагрузка от теней и анимаций; в простое постоянных замеров нет.

Настройки и сборки сохраняются между запусками. При первом запуске будет короткая настройка, её можно пропустить и вернуться к ней позже.

## Чего пока нет

- Входа через Microsoft.
- Управления мирами.
- Микшера приложений в Windows (в Linux и macOS он есть).
- Android и iOS не планируются.

Установщики собираются для Windows, Linux и macOS на Apple Silicon. Каталог модов работает, пока доступен Modrinth, перевод зависит от сторонних сервисов. Проверка модов может пропустить вредоносный файл или зря отметить нормальный.

## Сборка

Нужен JDK 21.

```bash
./gradlew :composeApp:run --console=plain
```

В Windows то же самое через `gradlew.bat`:

```bat
gradlew.bat :composeApp:run --console=plain
```

Desktop JAR:

```bash
./gradlew :composeApp:desktopJar --console=plain
```

Gradle берёт JDK из `JAVA_HOME` или первый найденный JDK 21. Если их несколько, задайте `JAVA_HOME` или добавьте в `~/.gradle/gradle.properties` строку `org.gradle.java.home=<путь к JDK 21>`.

## Релизы

GitHub Actions собирает MSI для Windows, DEB для Linux и DMG для Apple Silicon со встроенной Java. Для закрытого тестирования запустите workflow Release вручную на ветке и скачайте установщики из артефактов запуска.

Тег `vX.Y.Z` создаёт черновик предварительного релиза с установщиками и `SHA256SUMS.txt`. После проверки опубликуйте черновик. Лаунчер видит опубликованные обновления, включая беты, когда репозиторий релизов публичный.

## Новости

Лаунчер проверяет [ленту новостей](https://github.com/spikelauncher/news) при запуске. Чтобы опубликовать пост, измените `news.json` в ветке `main` репозитория ленты. При сбое загрузки используется последняя сохранённая лента или встроенные новости для первого запуска.
