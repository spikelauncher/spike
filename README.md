Лаунчер Minecraft для Windows, Linux и macOS на Kotlin Compose Desktop и Java.

Главная идея 2.0 — **сборки**. У каждой своя версия Minecraft, загрузчик, моды, ресурспаки, настройки и папка с игрой, поэтому наборы модов друг другу не мешают.

## Возможности

### Игра и профили

- Установка и запуск Minecraft: версии берутся из каталога Mojang.
- Сборки Vanilla, Fabric и Forge.
- Офлайн-профили без регистрации; для сторонних серверов авторизации есть вход через authlib-injector.
- История запусков и время в игре.
- Ghost Mode: на время игры окно лаунчера закрывается, запуск ведёт лёгкий фоновый процесс, а после выхода из игры лаунчер открывается снова.
- Экспериментальная поддержка Horizon — неофициальной реализации Minecraft на Rust.

### Моды и ресурспаки

- Поиск модов на Modrinth под версию и загрузчик сборки.
- Установка вместе с зависимостями, включение, выключение, обновление и удаление.
- Проверка сборки на дубликаты, отсутствующие зависимости и заявленные конфликты.
- Ресурспаки отдельно для каждой сборки: импорт, включение и выключение.
- Перевод описаний модов на русский через бесплатные веб-сервисы, без API-ключа. Включается в настройках.

### Безопасность экспериментов

- Точки восстановления сборки: сохраняют файлы сборки, но не миры, скриншоты, логи и кэш.
- Автообновление модов сохраняет заменённые файлы, так что обновление можно откатить.
- Проверка модов на подозрительные признаки (обфускация, запуск процессов и т. п.). Это эвристика, а не антивирус.

### Диагностика

- Логи каждой сборки.
- Разбор вылетов: лаунчер ищет известные ошибки и моды, классы которых есть в стеке.
- Если подозреваемый найден, игру можно проверить во временной копии сборки без этого мода.

### Производительность

- Автоподбор памяти и JVM-аргументов под Java, версию игры, моды и железо. Можно выставить вручную.
- Автоадаптация эффектов интерфейса: начальный режим учитывает CPU, память и программную отрисовку, затем корректируется по задержкам кадров. На слабом железе снижается нагрузка от теней и анимаций; в простое постоянных замеров нет.

### Рядом с игрой

- Список серверов выбранной сборки с проверкой доступности и пингом.
- Галерея скриншотов из игровых папок, привязанных к сборкам.
- Музыкальный плеер в боковой панели: радио Spike или поддерживаемый внешний проигрыватель.
- Светлая и тёмная темы, значки сборок, быстрое открытие папки сборки.
- Обновления через GitHub Releases: лаунчер скачивает установщик и сверяет SHA-256, а запускаете его вы. Автопроверку можно отключить.

Настройки и сборки сохраняются между запусками. При первом запуске будет короткая настройка, её можно пропустить и вернуться к ней позже.

## Установка

1. Откройте страницу [Releases](https://github.com/spikelauncher/spike/releases).
2. Скачайте установщик для своей системы:

   | Система | Формат |
   | --- | --- |
   | Windows | MSI |
   | Linux | DEB |
   | macOS (Apple Silicon) | DMG |

3. Запустите установщик. Java встроена, отдельно ставить её не нужно.
4. Сверить файл можно по `SHA256SUMS.txt` из того же релиза.

## Ограничения

Это бета, баги будут.

- Нет входа через Microsoft.
- Нет управления мирами.
- NeoForge пока не поддерживается.
- Микшера приложений в Windows нет (в Linux и macOS он есть).
- Android и iOS не планируются.
- Каталог модов работает, пока доступен Modrinth, а перевод зависит от сторонних сервисов.
- Проверка модов может пропустить вредоносный файл или зря отметить нормальный.
- Поддержка Horizon экспериментальная и может работать нестабильно.

## Сборка из исходников

Нужен JDK 21.

```bash
./gradlew :composeApp:run --console=plain
```

В Windows то же самое через `gradlew.bat`:

```bat
gradlew.bat :composeApp:run --console=plain
```

Desktop JAR:

```bash
./gradlew :composeApp:desktopJar --console=plain
```

Gradle берёт JDK из `JAVA_HOME` или первый найденный JDK 21. Если их несколько, задайте `JAVA_HOME` или добавьте в `~/.gradle/gradle.properties` строку `org.gradle.java.home=<путь к JDK 21>`.

## Релизы

GitHub Actions собирает MSI для Windows, DEB для Linux и DMG для Apple Silicon со встроенной Java. Для закрытого тестирования запустите workflow Release вручную на ветке и скачайте установщики из артефактов запуска.

Тег `vX.Y.Z` создаёт черновик предварительного релиза с установщиками и `SHA256SUMS.txt`. После проверки опубликуйте черновик. Лаунчер видит опубликованные обновления, включая беты, когда репозиторий релизов публичный.

## Новости

Лаунчер проверяет [ленту новостей](https://github.com/spikelauncher/news) при запуске. Чтобы опубликовать пост, измените `news.json` в ветке `main` репозитория ленты. При сбое загрузки используется последняя сохранённая лента или встроенные новости для первого запуска.
